# AnnouncementPlugin
Customizable announcement plugin for Paper 1.21.11
## Features

- Custom announcement messages
- Configurable colors and prefixes
- Automatic announcements
- Configurable command names
- Permission support

## Requirements

- Minecraft Paper 1.21.11
- Java 21

## Installation

1. Download the plugin JAR from Releases.
2. Put it into your server's plugins folder.
3. Restart your Paper server.
4. Edit plugins/AnnouncementPlugin/config.yml.

## Commands

- /announcement <message>
- /announcementrestart
